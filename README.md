# Pracownia 5TI4

Trening do części praktycznej egzaminu INF.03 (SQL, HTML/CSS, JavaScript, PHP, grafika, arkusze próbne) i do matury z matematyki – z automatycznym sprawdzaniem, w całości w przeglądarce.

- Online: GitHub Pages (Settings → Pages → branch `main`, folder `/ (root)`).
- Lokalnie na Windows: dwuklik `start.cmd`, potem http://localhost:8765/index.html.

Postęp zapisuje się w przeglądarce. Na inny komputer przenosisz go przyciskami „Pobierz postęp” / „Wczytaj” na stronie startowej.

Zadania z arkuszy CKE są podpisane źródłem (rok, sesja, numer zadania).
